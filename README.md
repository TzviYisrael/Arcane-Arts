# The Tower of Arcane Arts

A small Godot summoning game. Draw ink circles, place items, and summon creatures in your tower.

## Run

1. Open in Godot 4.6
2. Run the main scene (`Scenes/3D/main_room.tscn`)

## How to play

- Explore the main room of the tower
- Use the drawing desk to draw an ink circle
- Use the study desk to read books
- Place items on the summoning floor and start a ritual to summon animals, monsters, and demons

## Project layout

- `Scenes/` - 2D and 3D scenes
- `Scripts/` - gameplay, summons, resources
- `GameData/json/` - items, summons, books data
- `Assets/` - models and textures
